# Spec 02 — Architecture

## 1. Principles (unchanged from the original)

- Static files only. Opens by double-clicking `index.html` (`file://`) and from GitHub Pages.
- Plain `<script defer src>` in a fixed order; each file adds to one global object, **`window.LM`** (was `window.ELM`).
- No ES modules, no `fetch()`, no frameworks, no CDN. Fonts, icons and GSAP are local copies in `assets/`.
- Sources are Markdown and JSON; a Node build turns them into `.js` files that assign into `LM.*`. Big data is loaded on demand with `LM.loadModule(path)`.
- Pure logic lives in `*-logic.js` files with unit tests in `tools/tests.js`.

  chars: "á é í ó ú ü ñ ¿ ¡".split(" "),

  reportUrl: "https://github.com/<owner>/spanish-levels-map/issues/new?labels=content&title=",

Language-neutral files read `LM.APP` and `LM.lang`; they never contain Spanish words, letters or locale codes.

## 4. Build (`tools/build.js`)

`npm run build`: validate → `content/pages`, summaries, cheat sheets, home → `data/pages.js` · syllabus + levels → `data/syllabus.js` and the generated trail `data/trail.js` (E9) · quizzes → `data/quizzes-<level>.js` (lazy) · sets → `data/sets/<id>.js` (lazy) + `data/sets-index.js` · tests → `data/placement.js`, `data/final-<level>.js` (lazy) · decks → `data/decks-index.js`, `data/decks/<id>.js` (lazy) · lab → `data/lab.js` (lazy) · writing → `data/phrases.js`, `data/writing.js` (lazy) · exams → `data/exams-registry.js`, `data/exam-<id>.js` (lazy) · search index → `data/search-index.js` (lazy).

**Version stamp:** one number in `package.json` (`"lmVersion"`). `npm run build -- --bump` raises it and rewrites `?v=N` on every `<script>` and `<link>` in `index.html` and `LM.VERSION` (used by `LM.loadModule`). Nobody edits `?v=` by hand.

Every generated file starts with `/* GENERATED by tools/build.js — do not edit. Source: content/… */`.

## 5. Storage

- Prefix **`slm.`** for every key, including theme and sidebar. All schemas start at `version: 1`. No migrations.
- One **key registry** in `profile-data.js` drives export, import, reset and profile deletion; a unit test checks that every per-profile key is covered.

| Key | Was (original app) | Notes |

| `slm.theme`, `slm.sidebar` | `elm_theme_v1`, `elm_sidebar_v1` | device-wide, not exported |

## 6. Routes

Hash routing, English paths, no legacy redirects. Unknown routes show "Page not found" with a link home.

| Route | View |
|---|---|
| `#/` | home |
| `#/today` | Today |
| `#/trail` | Trail |
| `#/a1` … `#/c2` | level page |
| `#/a1/<category>-<slug>` | topic page (topic id without the level prefix) |
| `#/a1/test`, `#/a1/cheatsheet` | level final test, cheat sheet |
| `#/placement` | placement test |
| `#/review`, `#/review/decks[/…]`, `#/review/mistakes`, `#/review/words`, `#/review/session` | flashcards and mistakes |
| `#/practice`, `#/practice/set/<id>`, `#/practice/mix/<id>`, `#/practice/session`, `#/practice/weak[/<topic>]` | practice |
| `#/lab[/…]` | Tense & Mood Lab |
| `#/writing`, `#/writing/models/<exam>/<id>`, `#/writing/phrases[/<group>]` | writing |
| `#/stats`, `#/notes` | stats, notes |
| `#/exams/<exam id>[/…]` | exams from the registry |

## 7. File names

Polish file names of the original become English: `niezbednik.js → handbook.js`, `szlak*.js → trail*.js`, `fiszki*.js → cards*.js`, `powtorki.js → review.js`, `pisanie*.js → writing*.js` (full table: spec 03). Module names on `LM` follow the file names.

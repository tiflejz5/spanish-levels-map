# estar + gerundio: actions in progress

*Estar* + gerund (*gerundio*) works like English "be + -ing": *Estoy leyendo* (I'm reading). It describes an action in progress right now. But Spanish uses it less than English: the simple present can also describe what is happening (*¿Qué haces? —Leo.*), and it is **never** used for future plans. English "I'm leaving tomorrow" is *Mañana salgo* or *Mañana voy a salir*.

## How it works

**estar (present) + gerund**

| Person | estar | + gerund |
| --- | --- | --- |
| yo | estoy | hablando / comiendo / escribiendo |
| tú | estás | hablando / comiendo / escribiendo |
| él, ella, usted | está | hablando / comiendo / escribiendo |
| nosotros, nosotras | estamos | hablando / comiendo / escribiendo |
| vosotros, vosotras (Spain) | estáis | hablando / comiendo / escribiendo |
| ellos, ellas, ustedes | están | hablando / comiendo / escribiendo |

- Gerund: *-ar* → **-ando** (*hablando*), *-er* / *-ir* → **-iendo** (*comiendo, viviendo*).
- The gerund never changes: *Ella está comiendo. Ellos están comiendo.*

**Irregular gerunds**

| Pattern | Infinitive → gerund |
| --- | --- |
| vowel + *-er* / *-ir* → **-yendo** | leer → **leyendo**, oír → **oyendo**, traer → **trayendo** |
| irregular | ir → **yendo** |
| *-ir* verbs with e → i | pedir → **pidiendo**, decir → **diciendo**, servir → **sirviendo**, venir → **viniendo** |
| *-ir* verbs with o → u | dormir → **durmiendo**, morir → **muriendo** |

**Pronouns** go before *estar* or are attached to the gerund, which then needs an accent: *Me estoy duchando* = *Estoy duchándome. ¿Lo estás leyendo?* = *¿Estás leyéndolo?*

## When to use it

1. **Something happening right now.** *—¿Dónde está Lucía? —Está hablando por teléfono.* (She's on the phone.)
2. **A temporary situation these days.** *Estoy leyendo un libro muy bueno. Este mes estamos trabajando mucho.* (I'm reading a very good book. We're working a lot this month.)
3. **To stress that it is in progress** when the simple present could mean a habit: *Normalmente trabajo en casa, pero hoy estoy trabajando en la oficina.*

**Signal words:** *ahora, ahora mismo* (right now), *en este momento*, *estos días*, *hoy*.

## Examples

| Spanish | English |
| --- | --- |
| ¿Qué estás haciendo? | What are you doing? |
| Estoy preparando la cena. | I'm making dinner. |
| Los niños están durmiendo. | The children are sleeping. |
| No puedo hablar ahora, estoy conduciendo. (Spain; Latin America: manejando) | I can't talk now, I'm driving. |
| Está lloviendo mucho. | It's raining a lot. |
| Mi hermano está buscando trabajo. | My brother is looking for a job. |
| ¿Me estás escuchando? | Are you listening to me? |
| Estamos viendo una película. | We're watching a movie. |

## Good to know

- In the past, use the imperfect of *estar*: *Estaba leyendo cuando me llamaste.* (I was reading when you called.)
- Verbs like *tener, saber, conocer, querer* are not used in this form for states: *Tengo un coche* (I have a car), not *estoy teniendo*.
- *Ir* and *venir* rarely take it: *Ya voy* (I'm coming), *¿Vienes?* (Are you coming?).

## Common mistakes

- ✗ *Estoy yendo a Madrid mañana.* → ✓ *Mañana voy a Madrid.* — for plans, use the present or *ir a*, not *estar* + gerund.
- ✗ *Estoy leiendo.* → ✓ *Estoy leyendo.* — between vowels, *i* becomes *y*.
- ✗ *Soy trabajando.* → ✓ *Estoy trabajando.* — the helper verb is *estar*, not *ser*.
- ✗ *Nadando es bueno para la salud.* → ✓ *Nadar es bueno para la salud.* — as a noun ("swimming"), Spanish uses the infinitive.
- ✗ *Los niños están dormiendo.* → ✓ *Los niños están durmiendo.* — *dormir* changes o → u in the gerund.

## Practice

Write *estar* + gerund.

1. Ahora mismo yo ___ (escribir) un correo.
2. ¿Qué ___ (hacer) tú?
3. Mis padres ___ (dormir).
4. Paula ___ (leer) el periódico.
5. ___ (llover) desde esta mañana.

Translate into Spanish.

6. We're watching TV.
7. I'm taking a shower. (two ways)
8. I'm going to Lima tomorrow.

## Answers

1. estoy escribiendo
2. estás haciendo
3. están durmiendo
4. está leyendo
5. Está lloviendo
6. Estamos viendo la tele. / Estamos viendo la televisión.
7. Me estoy duchando. / Estoy duchándome.
8. Mañana voy a Lima. / Voy a Lima mañana. / Mañana voy a ir a Lima.

# A2 cheat sheet

## Forms

| Form | Pattern | Example |
| --- | --- | --- |
| preterite -ar | -é, -aste, -ó, -amos, -asteis, -aron | *Ayer hablé con Ana.* |
| preterite -er / -ir | -í, -iste, -ió, -imos, -isteis, -ieron | *Comimos en casa.* |
| irregular preterite | fui (ser / ir), tuve, estuve, hice / hizo, pude, puse, vine, dije | *El sábado fui a la playa.* |
| imperfect | -aba, -abas… / -ía, -ías…; era, iba, veía | *De niño jugaba en la calle.* |
| present perfect | he, has, ha, hemos, habéis, han + -ado / -ido | *Todavía no he comido.* |
| estar + gerund | estoy… + -ando / -iendo (leyendo, durmiendo) | *Estoy preparando la cena.* |
| future | infinitive + -é, -ás, -á, -emos, -éis, -án; tendré, haré, diré | *Mañana lloverá.* |
| imperative | tú: habla, come (di, haz, ve, pon, sal, ten, ven) · usted: hable, coma | *Gira a la derecha.* |

## Grammar

- **Preterite or imperfect?** Event, one time, closed period → preterite. Scene, habit, age, time → imperfect: *Dormía cuando sonó el teléfono.*
- **Object pronouns** before the verb: *lo, la, los, las* (it, him, her, them), *le, les* (to him / her / you / them). Personal *a* before a person: *Veo a María.*
- **Compare:** *más / menos … que*, *tan … como*, *el más alto de*; *mejor, peor*; *más de* + number.
- **por / para:** *para* = purpose, recipient, destination, deadline; *por* = cause, thanks, through a place, means, price.
- **saber / conocer:** facts and skills (*sé nadar*) / people and places (*conozco a Luis, conozco Lima*). **pedir / preguntar:** ask for / ask a question.

## Phrases

| Spanish | English |
| --- | --- |
| ¿Qué tal el fin de semana? | How was your weekend? |
| Lo pasé muy bien. (Latin America also: La pasé muy bien.) | I had a great time. |
| ¿Has estado alguna vez en…? | Have you ever been to…? |
| ¿Te apetece ir al cine? (Spain) / ¿Tienes ganas de…? | Do you feel like going to the movies? |
| Lo siento, no puedo. Es que… | Sorry, I can't. The thing is… |
| Perdone, ¿para ir a la estación? | Excuse me, how do I get to the station? |
| Siga todo recto (Latin America: derecho) y gire a la derecha. | Go straight ahead and turn right. |
| Quería reservar una mesa para dos. | I'd like to book a table for two. |
| El aire acondicionado no funciona. | The air conditioning doesn't work. |
| Me duele la cabeza. / Tengo fiebre. | I have a headache. / I have a fever. |
| ¿Tiene algo para la tos? | Do you have anything for a cough? |

## Signal words

| Spanish | English |
| --- | --- |
| ayer, anoche, el año pasado, hace dos años | yesterday, last night, last year, two years ago |
| antes, de niño, siempre, todos los veranos | before, as a child, always, every summer |
| mientras | while |
| ya, todavía no, alguna vez, nunca | already, not yet, ever, never |
| hoy, esta mañana, esta semana (Spain: perfect) | today, this morning, this week |
| ahora mismo, estos días | right now, these days |
| mañana, la semana que viene, pronto, algún día | tomorrow, next week, soon, one day |

## Watch out

- ✗ *Ayer he visto a Marta.* → ✓ *Ayer vi a Marta.*
- ✗ *Cuando fui niño, vivía en Cádiz.* → ✓ *Cuando era niño, vivía en Cádiz.*
- ✗ *Gracias para el regalo.* → ✓ *Gracias por el regalo.*
- ✗ *Lo voy a comprarlo.* → ✓ *Lo voy a comprar. / Voy a comprarlo.*
- ✗ *Yo también no.* → ✓ *Yo tampoco.*

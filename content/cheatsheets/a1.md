# A1 cheat sheet

## Forms

| Form | Pattern | Example |
| --- | --- | --- |
| ser | soy, eres, es, somos, sois, son | *Soy de Lima. Es médica.* |
| estar | estoy, estás, está, estamos, estáis, están | *Estoy en casa. Está cansado.* |
| tener | tengo, tienes, tiene, tenemos, tenéis, tienen | *Tengo dos hermanos.* |
| -ar / -er / -ir | -o, -as/-es, -a/-e, -amos/-emos/-imos, -áis/-éis/-ís, -an/-en | *hablo, comes, vivimos* |
| stem changes | e→ie, o→ue, e→i (not nosotros, vosotros) | *quiero, puedo, pido* |
| yo in -go | hago, salgo, pongo, tengo, traigo | *Salgo a las ocho.* |
| ir (a) | voy, vas, va, vamos, vais, van + a + infinitive | *Voy a estudiar.* |
| reflexive | me, te, se, nos, os, se + verb | *Me levanto a las siete.* |

## Grammar

- **Articles:** *el, la, los, las* / *un, una, unos, unas*; *a + el = al*, *de + el = del*. No article with a job: *Es profesor.*
- **Agreement:** *el chico alto*, *la chica alta*, *los chicos altos*; colors after the noun: *un coche rojo*.
- **ser / estar:** what it is (ser) vs where it is and how it is now (estar). Events: *La fiesta es en mi casa.*
- **hay / está:** *Hay un banco* (something new) / *El banco está allí* (a known thing).
- **gustar:** *me / te / le / nos / os / les* + *gusta* (one thing, an action) / *gustan* (plural).
- **Questions and no:** *¿Dónde vives? No vivo aquí. No tengo nada.* Question words have accents.
- **Possessives / demonstratives:** *mi, tu, su, nuestro*; *este, ese, aquel*.

## Phrases

| Spanish | English |
| --- | --- |
| Hola, me llamo… Mucho gusto. | Hi, my name is… Nice to meet you. |
| ¿De dónde eres? —Soy de… | Where are you from? —I'm from… |
| ¿Cuántos años tienes? —Tengo… años. | How old are you? —I'm… |
| ¿A qué te dedicas? —Soy… | What do you do? —I'm a… |
| ¿Qué hora es? —Son las tres y media. | What time is it? —It's half past three. |
| ¿A qué hora abre? | What time does it open? |
| ¿Hay un banco por aquí? | Is there a bank around here? |
| Quería un café, por favor. | I'd like a coffee, please. |
| ¿Cuánto cuesta? / ¿Cuánto es? | How much is it? |
| La cuenta, por favor. | The check, please. |
| ¿Puede repetir, por favor? | Can you repeat that, please? |
| Más despacio, por favor. | Slower, please. |
| ¿Cómo se dice … en español? | How do you say … in Spanish? |
| Me gusta… / No me gusta… | I like… / I don't like… |

## Signal words

| Spanish | English |
| --- | --- |
| siempre / a veces / nunca | always / sometimes / never |
| todos los días / los lunes | every day / on Mondays |
| por la mañana / tarde / noche | in the morning / afternoon / at night |
| a las ocho | at eight |
| hoy / mañana / esta noche | today / tomorrow / tonight |
| el fin de semana | on the weekend |
| en julio / en verano | in July / in summer |
| aquí / ahí / allí (Latin America also acá / allá) | here / there / over there |

## Watch out

- ✗ *Soy 25 años.* → ✓ *Tengo 25 años.*
- ✗ *Soy cansado.* → ✓ *Estoy cansado.*
- ✗ *Yo gusto el café.* → ✓ *Me gusta el café.*
- ✗ *la casa blanco* → ✓ *la casa blanca*
- ✗ *en el lunes* → ✓ *el lunes*
